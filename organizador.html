Conectar ao GitHub

Uma vez só. Depois disso, é um botão e pronto — sem baixar, sem arrastar, sem commit.

1
Abre esta página do GitHub.
2
Em Token name, escreve organizador.
3
Em Expiration, escolhe 1 year. Serve para fechar a janela: se a chave vazar um dia, ela deixa de valer sozinha. Se preferir No expiration, tudo bem também — dá para apagar a chave a qualquer momento, num clique, e gerar outra.
4
Em Repository access, marca Only select repositories e escolhe mix. Assim a chave não alcança mais nada seu.
5
Em Permissions, clica em + Add permissions. Abre uma caixa branca com um campo de busca. Busca por Contents — não por “Repository”. Repository é a categoria, não existe permissão com esse nome, e a busca não acha nada útil. Marca Contents e põe em Read and write. O Metadata aparece sozinho como obrigatório e não dá para tirar — o contador mostrar 2 está certo.
6
Generate token, copia o código e cola aqui embaixo. O GitHub mostra o código uma vez só. Se fechar a página sem copiar, é só gerar outro — não tem problema.

Ela fica guardada só neste navegador, no seu computador. Não vai para lugar nenhum além do próprio GitHub. Quando ela vencer, o botão Salvar avisa em vermelho — é só voltar aqui e colar uma nova.

Tags e ordem

As de cima aparecem na barra do site. As de baixo ficam escondidas atrás do +. Arraste a linha do corte para decidir quantas ficam à vista.
